Com Client launcher Newest version Download for Windows

Windows 10 or 11, 64-bit.

From download to playing

About five minutes, most of it the first download.

  1. Run the installer

    Open the file you downloaded. If Windows shows "Windows protected your PC", click More info and then Run anyway. That message appears for new apps that aren't widely downloaded yet.

  2. Sign in with Microsoft

    Use the Microsoft account that owns Minecraft Java Edition. You can add more accounts later and switch in one click.

  3. Press Play

    The first start downloads Minecraft, Java and the mods, a few hundred MB. Later starts are quick.

What it installs

  • Minecraft 1.21.11 and the right Java, from Mojang
  • Fabric, Sodium, Lithium and the other speed mods
  • Com Client, updated by itself
  • Nothing else: no toolbars, no ads, no background services

Everything lives in its own folder, separate from the normal Minecraft launcher. Nothing there is changed, and the launcher can copy over your settings, keybinds and server list.
