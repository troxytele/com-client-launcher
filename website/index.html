Questions

Good to know

Is Com Client free?

Yes. The client, the launcher and the cosmetics are free.

Can I get banned for using it?

Com Client only has visual and quality-of-life modules: no cheats, no unfair advantages. Some servers have their own rules about client mods, so check the rules of the server you play on.

Which Minecraft version?

Minecraft Java Edition 1.21.11 with Fabric. You need a Minecraft Java account (Microsoft sign-in).

Do I need to install Java or Fabric?

No. The launcher downloads Minecraft, Java, Fabric and Com Client by itself and keeps them up to date.

Can I use my own mods?

Yes. Every profile has its own mods folder, and the launcher has a Modrinth browser for mods, resource packs, shaders and whole modpacks.

Ready to play?

Download the launcher, sign in with Microsoft and press Play. That's it.
